# Netflix-Viewership-Content-Analytics-Dashboard
An interactive Power BI dashboard analyzing Netflix viewership, customer demographics, and content performance.
# Overview
This project turns Netflix viewership and rating data into a 5-page report covering audience behavior, content performance, and strategy insights — built with data modeling, DAX, and interactive visuals.
# Dashboard Pages
- Overview — Audience, content, and engagement KPIs
- Customer Insights — Demographics by age, gender, country, subscription
- Content Insights — Genre, rating, and watch-time performance
- Content Strategy — Content investment and performance view
- Content Discovery — Top-rated titles and viewing trends
# Key Metrics
Total Watch Time, Average User Rating, Most Popular Genre, Watch Time per Customer, % of Total Customers, Content Age & Viewer Level segments.
# Tools Used
Power BI Desktop · Power Query · DAX
# How to Use
- Download-netflix_power_bi.pbix
- Open it in Power BI Desktop
- Use the slicers and navigation buttons to explore each page
